# Release v1.3.01 (2026-11-06)

Visual identity and design refresh.

## What's Changed
- **New Icon & Branding**: 3x3 puzzle board with glowing amber centre spark ("the wise cell") on an indigo-to-violet gradient; matching themed adaptive monochrome icon and splash screen.
- **Custom Palette**: Midnight indigo + amber primary styling; system wallpaper colors made optional.
- **Serif Typography**: bold serif printed clues, italic indigo handwriting pen digits, framed board, circular cell indicators, timer pill.
- **Refined Home Screen**: living breathing logo, two-tone wordmark, active game progress card, difficulty dots, quick navigation tiles.
- **Dialog & Settings**: hints display on win dialog, split appearance and gameplay settings.
