# Release v1.5.0 (2026-11-06)

Appearance themes, haptic feedback, left-handed mode, and accessibility.

## What's Changed
- **Appearance & Color Themes**: Theme mode selection (System, Light, Dark) and 4 custom accent palettes (Indigo, Teal, Rose, Forest) with Amber accent.
- **Haptic Feedback**: light tick vibrations on cell/pad selection, distinct feedback on mistake and completion.
- **Left-Handed Layout**: mirrored header and tool action buttons for left-hand thumb reach.
- **Accessibility Enhancements**: high contrast grid styling, enlarged digit view, reduce motion mode (respects Android system animation scale), full TalkBack content descriptions.
- **Local File Backup**: "Save to this phone..." export directly via system storage file picker.
- **Backup Support**: user settings state preserved across export/import cycles.
